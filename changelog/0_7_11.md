- **Android 返回键 / 侧滑返回**：在原生壳内统一响应系统返回；先关闭当前浮层（设置、选项、牌库/详情预览、收藏预览等），收藏页与主菜单再逐级返回；主菜单无浮层时退出应用。
- 需重新执行 `npm run cap:sync`（或打 APK 流程）以将 `@capacitor/app` 同步进 Android 工程。
