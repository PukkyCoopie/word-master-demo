# Word Master（word-master-demo）

Balatro-like word-spelling game demo.  
Completely built using vibe coding.

**Libs and 3rd-party resources**：Vue 3、Vite、GSAP、regl、Remix Icon； 
**Shaders from** <a href="https://www.shadertoy.com/" target="_blank" rel="noopener noreferrer">Shadertoy</a>

```bash
npm install && npm run dev
```

### 更新日志

`changelog/` 下按版本存放 `major_minor_patch.md`；frontmatter 中 `show: true` 的才会出现在游戏更新日志（详见 `changelog/README.md`）。**commit 时**若最新版未手写说明，会把 commit 说明写入该 md（`show: false`）；**commit 后**自动准备下一版文件并同步版本号。
