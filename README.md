# Word Master（word-master-demo）

Balatro-like word-spelling game demo.  
Completely built using vibe coding.

**Libs and 3rd-party resources**：Vue 3、Vite、GSAP、regl、Remix Icon； 
**Shaders from** [Shadertoy](https://www.shadertoy.com/)

```bash
npm install && npm run dev
```

## 版本与更新日志

- 展示版本：`src/appVersion.json`（关于弹窗读取 `src/appVersion.js`）。
- **每次 `git commit`** 自动 **patch +1**；**更新日志正文 = 本次 git 提交说明**（优先正文，否则用标题）。
- **中/大版本**：`npm run version:minor` / `version:major` 后再 `git commit`。
- 跳过自动 bump：`SKIP_VERSION_BUMP=1 git commit …`
