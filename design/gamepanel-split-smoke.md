# GamePanel 拆分 — 手测 Smoke 清单

> 每个架构拆分任务完成后，至少跑与本任务相关的条目；Phase 9 跑全表。  
> 在 **Vite dev** 下测试；勾选 `[ ]` → `[x]`。

---

## 环境

- [ ] `npm run dev` 已启动，HMR 正常
- [ ] 使用可清空的测试存档槽（或 dev 控制台清档）

---

## 1. 新局与棋盘

- [ ] 主菜单开新局，1-1 棋盘 4×4 正常落子
- [ ] 点格选字入词槽，再点词槽退回棋盘
- [ ] 词槽内拖放重排（非青铃锁位）
- [ ] 顶栏：当前分 / 目标分 / 剩余出牌 / 弃牌次数显示正确

---

## 2. 拼词提交

- [ ] 提交合法词：计分动画完整，分数累加
- [ ] 提交后补牌 / 重力正常
- [ ] 非法词 / 空词：提交按钮不可用或 toast
- [ ] 结算条（ResultArea）与词义按钮（若开启）正常

---

## 3. 弃牌

- [ ] 选字后 discard，次数 -1，补牌动画
- [ ] 弃牌次数用尽后按钮不可用
- [ ] 单次上限（8 格）提示正常

---

## 4. 商店

- [ ] 小关达标进商店 portal，主棋盘不可点
- [ ] 购买宝藏 / 升级 / reroll 扣费正确
- [ ] 「下一关」进新小关，分数重置、出牌次数恢复
- [ ] 商店内开牌库预览、暂停选项

---

## 5. 宝藏栏

- [ ] 底部宝藏栏展示、叠放模式（多宝藏）
- [ ] 打开宝藏全览、重排（若已拥有多个）
- [ ] /footer 充能条（有充能宝藏）显示与更新

---

## 6. 存档

- [ ] 拼词后刷新页面，续玩棋盘/分数/牌库一致
- [ ] 商店内刷新，仍在商店且货架状态合理
- [ ] 结算界面刷新，phase 正确

---

## 7. Boss

- [ ] 进入 x-3 Boss 关：条带 / 机制生效（任选熟悉 Boss 测一条）
